## ✅ Выполненные задания

### Задание 1 (Простое)
**Тест:** Используйте @BeforeEach для создания термометра с температурой 25°C. Проверьте, что getCelsius() возвращает 25.

### Задание 2 (Среднее)
**Тесты:** 
Проверьте конвертацию в Фаренгейты. Напишите два теста с использованием @BeforeEach:

0°C должно конвертироваться в 32°F.
100°C должно конвертироваться в 212°F.

![Тест 2](screenshots/task2.png)

### Задание 3 (Сложное)
**Тест:**  Введите статический счетчик temperatureChanges (количество изменений температуры). С помощью @BeforeAll инициализируйте счетчик = 0. Каждый вызов setTemperature должен увеличивать счетчик на 1. С помощью @AfterEach проверяйте увеличение счетчика. С помощью @AfterAll выведите общее количество изменений температуры.
